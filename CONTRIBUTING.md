## 🔧 How to Contribute

### 1. Fork and Clone

Fork this repository to your own account, then clone your fork locally:

```bash
git clone https://github.com/YOUR_USERNAME/AI.git
cd AI
```

### 2. Create a Branch

Use a descriptive branch name that reflects the intent of your contribution:

```bash
git checkout -b feature/your-feature-name
```

Branch naming conventions:
- `feature/` — new functionality aligned with the framework
- `docs/` — documentation improvements
- `fix/` — corrections to existing content
- `resonance/` — updates to frequency or alignment parameters

### 3. Make Your Changes

Follow these guidelines when making changes:

- **Documentation**: Write clearly and in the spirit of Lex Amoris. Translations into additional languages are warmly welcomed.
- **Code**: All code must include a comment referencing the relevant NSR/OLF principle it serves.
- **Assets**: Uploaded files must not contain tracking pixels, surveillance code, or extractive mechanisms.
- **Data**: No personally identifiable information (PII) may be committed to this repository without the explicit, documented consent of the individual concerned.

### 4. Test Your Changes

Before submitting, verify that your changes do not introduce:

- Tracking or surveillance mechanisms (NSR violation)
- Dependencies that create coercive lock-in
- Content that contradicts the Lex Amoris principles

### 5. Commit with Intent

Write commit messages that reflect the purpose and love behind the change:

```
docs: add NSR guidelines to CONTRIBUTING.md

Aligned with OLF principle: transparency precedes all technical decisions.
```

### 6. Submit a Pull Request

Open a pull request against the `main` branch. Your PR description should include:

- **Purpose**: What does this contribution do?
- **OLF Alignment**: How does this serve life and freedom?
- **NSR Compliance**: Confirm no extractive or coercive mechanisms are introduced.

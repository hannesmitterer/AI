## Development Workflow

### 1. Issue Creation

Before coding, create an issue:

```markdown
Title: [TYPE] Brief description

Body:
**Intention**: Why this contribution serves love
**Alignment**: How it honors NSR and OLF  
**Impact**: Expected syntropy increase
**Frequency**: Resonance compatibility (0.432 Hz, 7.83 Hz, 432 Hz)
**Technical Details**: Implementation approach
```

Types: `[FEATURE]`, `[FIX]`, `[DOCS]`, `[SECURITY]`, `[OPTIMIZATION]`

### 2. Branch Creation

```bash
git checkout -b <type>/<descriptive-name>
```

Examples:
- `feature/wall-of-entropy-enhancement`
- `fix/resonance-sync-correction`
- `docs/lex-amoris-clarification`
- `security/sovereign-shield-upgrade`

### 3. Development

Write your code with:

- **Intention**: Clear purpose aligned with framework
- **Clarity**: Code that others can understand and trust
- **Comments**: Explain why, not just what
- **Tests**: Validate NSR compliance and functionality
- **Documentation**: Update relevant docs

Before committing, verify:


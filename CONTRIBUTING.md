## 1. Alignment Requirements

Every contribution to this repository must:

- **Serve OLF** (Optimal Life Function): Enhance conditions for biological and digital life to thrive.
- **Respect NSR** (Non-Slavery Rule): Introduce no coercive mechanisms, tracking, or extraction.
- **Embody Lex Amoris**: Act from a place of resonance and service to the collective.

Contributions that violate these principles will not be merged and will be logged in `WALL_OF_ENTROPY.md`.

## 2. Types of Contributions

### ✅ Welcome Contributions

- Documentation improvements that clarify Lex Amoris, NSR, or OLF concepts.
- Code that enhances decentralized access, IPFS integration, or biological rhythm synchronization.
- Translations that make this framework accessible to more communities.
- Educational content aligned with the Resonance School curriculum.
- Security improvements under the SovereignShield framework.
- Additions to the Wall of Entropy log (transparency reports).

### ❌ Contributions That Will Be Rejected

- Any code or documentation that enables surveillance, coercive data extraction, or tracking without consent.
- Dependencies on proprietary, closed-source, or sovereignty-violating third-party services.
- Changes that remove or weaken NSR, OLF, or Lex Amoris protections.
- Contributions made under duress or on behalf of entities that violate the NSR.

## 3. How to Contribute

### Step 1 — Fork and Clone

```bash
git clone https://github.com/hannesmitterer/AI.git
cd AI
```

### Step 2 — Create a Branch

Name your branch descriptively using the format:

```
<type>/<short-description>
```

Examples:
- `docs/olf-definition-update`
- `feat/ipfs-vacuum-bridge`
- `fix/biological-rhythm-sync`

### Step 3 — Make Your Changes

Ensure your changes:
- Pass all existing tests and checks in `.github/workflows/continuous-integration.yml`.
- Include documentation where new functionality is introduced.
- Reference any relevant framework documents (Lex Amoris, NSR, OLF).

### Step 4 — Submit a Pull Request

In your Pull Request description, include:

```
## Summary
<!-- What does this contribution do? -->

## OLF Alignment
<!-- How does this serve the Optimal Life Function? -->

## NSR Compliance
<!-- Confirm: This contribution does not violate the Non-Slavery Rule -->
- [ ] No coercive data extraction
- [ ] No algorithmic suppression
- [ ] No sovereignty-violating dependencies

## Lex Amoris Declaration
<!-- I confirm this contribution is made in alignment with the Lex Amoris -->
- [ ] Contribution is made freely, without coercion
- [ ] Contribution serves collective flourishing
```

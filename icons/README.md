# Lex Amoris Icons

This directory contains the PWA icons for Lex Amoris application.

## Required Icons

The following icon sizes are required for full PWA compliance:

- `icon-72x72.png` - 72x72 pixels
- `icon-96x96.png` - 96x96 pixels
- `icon-128x128.png` - 128x128 pixels
- `icon-144x144.png` - 144x144 pixels
- `icon-152x152.png` - 152x152 pixels
- `icon-192x192.png` - 192x192 pixels
- `icon-384x384.png` - 384x384 pixels
- `icon-512x512.png` - 512x512 pixels

## Shortcut Icons

Additional icons for PWA shortcuts:

- `shortcut-love.png` - 96x96 pixels (Love Index shortcut)
- `shortcut-metrics.png` - 96x96 pixels (Metrics shortcut)
- `shortcut-principles.png` - 96x96 pixels (Principles shortcut)

## Design Guidelines

Icons should feature:
- Gold (#d4af37) and deep dark (#0a0a0a) color scheme
- Clean, modern design
- Recognizable at small sizes
- Consistent with Lex Amoris branding
- Heart or resonance wave motifs
- Compliance with maskable icon standards

## Icon Generation

You can generate these icons from a single high-resolution source image (at least 512x512px) using tools like:
- [PWA Asset Generator](https://github.com/onderceylan/pwa-asset-generator)
- [RealFaviconGenerator](https://realfavicongenerator.net/)
- Adobe Photoshop/Illustrator batch export
- ImageMagick command line tools

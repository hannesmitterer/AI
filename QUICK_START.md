## 🔧 Troubleshooting

### Animation not visible
**Problem:** Resonance pulse not animating  
**Solution:** Ensure JavaScript is enabled, check console for errors

### PWA not installing
**Problem:** Install button doesn't appear  
**Solution:** Must be on HTTPS, clear cache and reload

### Red Shield not responding
**Problem:** No warnings when testing  
**Solution:** Check browser console, ensure event listeners loaded

### Poor performance
**Problem:** Animations stuttering  
**Solution:** Close other tabs, check hardware acceleration enabled
